# Super Pixel Bros

A little browser game made with plain HTML and JavaScript: four platformer levels plus a kart racing cup.

## How to play

1. Download this repo (green **Code** button → **Download ZIP**) and unzip it.
2. Double-click `index.html` to open it in your browser.
3. Press any key to turn the sound on.

Keep `index.html` and `kart.js` in the same folder. You need a keyboard.

## Controls

**Home page:** ←/→ pick a character, ↑/↓ pick a level, **Tab** switches between Adventure and Kart Racing, **Enter** starts.

**Adventure:** ←/→ move, **Space** jump (tap to swim under water; Peach can hold it to float), **Esc** menu, **M** sound on/off.

**Kart racing:** ↑ gas, ↓ brake, ←/→ steer, **Space** use item, **Esc** menu.
